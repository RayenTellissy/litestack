Every part of the request works now. `search` finds open tasks by title and ignores case. `--all` adds done tasks. The output looks exactly like `list`. When nothing matches it prints `No matching tasks.` and exits with status 1. I checked each of these by running the real CLI and kept the output.

**What you can do now**
- `python3 -m tasks search milk` lists the open tasks whose title contains "milk" in any case, such as `[ ] 3 Oat MILK #shop`.
- `python3 -m tasks search milk --all` also lists done tasks, such as `[x] 1 Buy milk #home`.
- `python3 -m tasks search bread` prints `No matching tasks.` and exits with status 1.
- The README has a new example line for it.

**How it's built**
- I added no new type or data format. `search` has two inputs, the text and `--all`. It filters the same task list that `list` uses and prints each task with the same line function.
- It lives in `tasks/cli.py` as `cmd_search`, right next to `cmd_list`, with its own subcommand. `cmd_list` was the closest existing code, so I built to match it and skipped the separate design step.
